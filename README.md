# 批量改名器

Windows 上用的小工具：批量重命名文件/文件夹，外加批量新建文件夹和空文件。

单文件 exe，基于 .NET Framework 4.8（Win10/11 自带），不需要装任何运行环境，也不需要管理员权限。

## 用法

1. 双击 `BatchRenamer.exe`
2. 把文件拖进窗口，或点「添加文件 / 添加文件夹」
3. 左侧选规则类型 → 点「添加规则」→ 配置 → 右侧立刻能看到改名后的样子
4. 红色行是有问题的（重名、已存在、非法字符），会被自动跳过
5. 点「执行改名」，改错了点「撤销上一批」

## 规则

- 查找替换（支持正则、忽略大小写、只改主名）
- 插入文字（开头 / 结尾 / 第 N 个字符后）
- 删除 / 截取（按位置，或按分隔符删掉某一段）
- 序号（起始、步长、补零位数、插哪里或整个替换）
- 日期（修改时间 / 创建时间 / 当前时间，格式自定义）
- 大小写（全大写 / 全小写 / 首字母大写）
- 清理字符（去首尾空格、合并空格、去括号内容、去特殊符号、全角转半角）
- 扩展名（改扩展名或去掉扩展名）

规则从上到下依次作用，可以拖动顺序（↑ ↓），双击一条规则可以修改。

## 批量新建

第二个标签页：选目标文件夹，指定建文件夹还是空文件，按「序号 / 名单 / 日期+序号」生成，支持前缀后缀，先预览再创建。

## 说明

- 改名和撤销的操作记录写在 `%LOCALAPPDATA%\BatchRenamer\log.txt`
- 超过 260 字符的路径会自动加 `\\?\` 前缀处理
